# SOC Analyst Toolkit 🔐

A Python-based cybersecurity project designed to support security log analysis, suspicious activity detection, incident investigation, and AI-assisted security operations.

## 🎯 Project Objective

The goal of this project is to develop a practical Security Operations Center (SOC) investigation toolkit that helps analyze security events, identify suspicious behavior, and generate useful incident reports.

This project is being developed incrementally alongside hands-on cybersecurity and Python training.

## 🚀 Planned Features

- Security alert management
- Windows Event Log analysis
- Failed login detection
- Suspicious IP activity detection
- Rule-based threat detection
- Risk scoring and incident classification
- Automated investigation reports
- AI-assisted security analysis
- SOC monitoring dashboard

## 🛠️ Technologies

- Python
- Linux
- Windows Event Logs
- Git and GitHub
- JSON and CSV
- MITRE ATT&CK
- Streamlit
- AI/LLM integration
